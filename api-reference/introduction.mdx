Flovoo's API lets you read and manage the same data your team sees in the dashboard — contacts, conversations, messages, templates, broadcasts and more. Endpoints on this page are grouped by resource: Contacts, Conversations, Messages, Tags, Contact Stages, Segments, Quick Replies, Custom Fields, Broadcasts, WhatsApp Templates, Users, Channels, and Webhooks.

## API versions

Flovoo currently ships one public API version:

- **v1** — every endpoint under **Endpoints** in the sidebar. Paths use the `/v1/...` prefix.

There is no legacy version to migrate away from — v1 is the only one, and it's where new endpoints are added as the API grows.
